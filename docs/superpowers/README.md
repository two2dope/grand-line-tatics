# Especificações e Planos de Engenharia (Superpowers)

Este diretório armazena especificações de design aprovadas (`specs/`) e planos de execução (`plans/`) versionados com prefixo ISO 8601 (`YYYY-MM-DD`) conforme as diretrizes de governança de repositório do projeto.

- `specs/` — Documentos de arquitetura funcional, decisões de design e contratos antes da implementação.
- `plans/` — Planos sequenciais orientados a tarefas e verificação automatizada.
